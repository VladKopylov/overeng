# ADR 0010: Debug-лог `overlay-debug.log`

- **Status:** Accepted
- **Date:** 2026-10-17

## Context

Поведінку оверлея над іграми (фокус, topmost, hotkeys) можна перевірити лише на Windows ПК, де немає зручного дебагера. Для gate-рішення кроку 1 потрібен лог із таймстампами.

## Decision

- Лог пишеться у `overlay-debug.log` у папці логів застосунку (`app.path().app_log_dir()`). Кожен рядок дублюється в stdout (видно в `npm run tauri dev`).
- Формат часу: `секунди_unix.мілісекунди (HH:MM:SS UTC)`, лише зі стандартної бібліотеки, без додаткових крейтів. Якщо годинник «до 1970», беремо 0.
- **Ротація** при старті: якщо файл більший за 1 MB (`MAX_LOG_BYTES`), він перейменовується на `overlay-debug.log.old`, щоб лог не ріс вічно.
- JS пише в той самий лог через команду `debug_log` (з префіксом `[js]`; вікно налаштувань додає `[settings]`).
- Помилки логування лише друкуються в stderr: лог не повинен ламати застосунок.
- Логуються: старт, реєстрація й натискання hotkeys, зміни фокусу, `reassert_topmost` (включно з тим, чи вже стояв `WS_EX_NOACTIVATE`), позиціонування, синк і його помилки, збереження налаштувань.
- **Токен ніколи не логується**: `set_token` пише лише «токен збережено» або «токен видалено» (див. [0005](0005-notion-token-rust-only.md)).

## Consequences

- На диску зберігається щонайбільше приблизно 2 MB логів (поточний файл + `.old`).
- Лог — головне джерело даних для `docs/spike-results.md`.
- `*.log` ігнорується в git.
