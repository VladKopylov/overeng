# ADR 0009: Кеш карток і захист синку

- **Status:** Accepted
- **Date:** 2026-10-17

## Context

Оверлей має показувати картки навіть без мережі. Синк можуть запустити одночасно автосинк при старті й кнопка в налаштуваннях. Невдалий синк не повинен знищити вже наявні картки.

## Decision

**Кеш** — `cards.json` у папці даних застосунку (поруч зі store), з полями `synced_at` (секунди unix) і `cards`.

- Кеш перезаписуємо **лише після успішного завантаження всіх сторінок**. При будь-якій помилці старий кеш лишається, тому тексти помилок мережі й 429 кажуть «кеш карток збережено».
- Запис **атомарний**: спершу у `cards.json.tmp`, потім `rename`. Якщо запис обірветься, старий `cards.json` лишиться цілим.
- Читання: якщо файлу нема, це порожній список (ще не синкали); зіпсований файл — помилка `Storage`.
- Поки кеш порожній або читання не вдалося, оверлей показує 3 вбудовані запасні фрази. Картки з кешу перемішуються (Fisher–Yates на копії масиву).

**Захист від двох синків одночасно:**

- `SyncState { running: AtomicBool }` реєструється через `.manage(...)`. `AtomicBool` можна безпечно міняти з різних потоків без `Mutex`.
- `running.swap(true)` повертає старе значення: якщо вже було `true`, повертаємо `NotionError::Busy`.
- Прапорець скидає RAII-guard `ResetOnDrop`: його `Drop` ставить `false` після завершення функції, помилки (`?`) і навіть паніки.

**Автосинк при старті:** якщо є токен і вибраний data source, синк запускається у фоні (`tauri::async_runtime::spawn`) без показу чи фокусування вікон. Якщо токена нема (перший запуск, ще поза грою), відкриваємо налаштування.

**Оновлення оверлея:**

- Після успішного синку (і після `set_settings`) Rust шле `cards-updated` лише вікну `overlay`.
- Оверлей **спершу підписується** на `cards-updated` і лише потім уперше читає кеш (у `finally` після `listen`), тож подія синку, що прийшла під час старту, не губиться.
- `reload` має лічильник `seq`: якщо два reload-и перекрилися, застосовується лише найновіший результат, а після демонтажу результат ігнорується.

## Consequences

- Оверлей працює офлайн з останнім успішним кешем.
- Паралельний запуск синку дає зрозуміле повідомлення «Синхронізація вже триває».
- Немає гонки між стартом оверлея й автосинком.
